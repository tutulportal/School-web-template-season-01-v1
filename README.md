# 🏫 ABCD School & College - Web Template v1

![Project Version](https://img.shields.io/badge/Version-1.0.0-emerald)
![Tech Stack](https://img.shields.io/badge/Tech-HTML%20%7C%20Tailwind%20%7C%20JS-blue)
![Status](https://img.shields.io/badge/Status-Complete-success)

**ABCD School & College** is a premium, modern, and fully responsive web template designed specifically for educational institutions. This template focuses on high-fidelity visual design, smooth interactive elements, and a clean user experience.

---

## ✨ Key Features

- 🚀 **Interactive Hero Slider**: High-performance slider with cinematic zoom effects and drag support.
- 🔄 **Infinite Message Carousel**: Seamlessly looping slider for principal and faculty messages.
- 🖼️ **Dynamic Gallery Slider**: Infinite image gallery with isolated hover zoom effects for a professional feel.
- 📱 **Fully Responsive**: Optimized for all devices—from large desktops to small mobile screens.
- 🔔 **Notice Board**: Dedicated section for urgent updates and notifications.
- 📊 **Student Statistics**: Visual counter/statistics section for student distribution.
- 🎓 **Best Student Showcase**: Beautifully designed grid for highlighting top achievers.
- 🔝 **Progress Scroll-to-Top**: Modern scroll-to-top button with a circular progress indicator.
- 💎 **Glassmorphism UI**: Clean, semi-transparent header and interactive elements.

## 🚀 How to Use

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/tutulportal/School-web-template-season-01-v1.git
   ```

2. **Open the Project:**
   Simply open `index.html` in any modern web browser. No compilation or installation is required.

3. **Customize:**
   - Modify the `index.html` to update school names, messages, and student data.
   - Replace image URLs with your institution's photos.
